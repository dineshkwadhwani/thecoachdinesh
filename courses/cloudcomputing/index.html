Learning Outcomes

What you will understand

A practical foundation in the controls that keep cloud infrastructure configured safely and users authenticated appropriately.

Shared responsibility

Separate provider responsibilities from customer responsibilities across IaaS, PaaS, and SaaS.

Cloud security pillars

Relate identity, data protection, network controls, governance, and monitoring to real cloud systems.

CSPM operations

Explain how continuous discovery and assessment turn configuration findings into prioritized remediation.

Security tool boundaries

Distinguish CSPM from CWPP, CIEM, and KSPM, and understand CNAPP as an umbrella platform.

SSO protocols

Choose between SAML, OAuth 2.0, and OpenID Connect by understanding what each is designed to do.

Identity risk controls

Connect MFA, short-lived tokens, minimal permissions, and secure session handling to common risks.

Course Architecture

One session, two connected lectures

The first lecture protects the cloud environment behind the login. The second explains how that login works across trusted services.
