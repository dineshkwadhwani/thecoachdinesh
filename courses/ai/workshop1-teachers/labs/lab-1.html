Lab 1 · Prompting

Prompt engineering:
make the task testable.

Use RCTFG to turn an academic task into a prompt with an explicit role, context, task, format, and guardrails.

What you will do

Start with a vague question-paper request. Add the course context, learning outcomes, constraints, and output format. Then test the prompt with an out-of-scope request and inspect what the model does.

The goal is not a clever sentence. It is a specification that another person can run and critique.

Finish with

  • Prompt A reusable RCTFG prompt
  • Test One in-scope and one out-of-scope result
  • Evidence Checkpoint notes
