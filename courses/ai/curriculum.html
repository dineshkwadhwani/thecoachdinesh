Course Objectives

What Students Will Be Able To Do

✓Understand the fundamentals of Generative AI and how Large Language Models work at a mechanistic level
✓Design effective prompts for diverse production use cases using systematic engineering techniques
✓Build AI-powered applications using both proprietary APIs (OpenAI, Anthropic) and open-source tools
✓Architect Retrieval-Augmented Generation systems with embeddings, vector databases, and semantic search
✓Evaluate AI systems rigorously — create benchmarks, run A/B tests, and monitor production performance
✓Deploy AI systems to production with appropriate infrastructure, scaling, and cost optimisation strategies
✓Assess AI systems for bias, explain decisions, and implement responsible AI governance practices
✓Design multi-agent systems that plan, use tools, maintain memory, and act with genuine autonomy
