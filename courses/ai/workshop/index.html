A workshop in ten builds

Every lab has a job.

Participants start with saved prompts and fixed sequences, then cross the line into agents that reason, call tools, and make decisions.

01–02

Prompts & Gems

Build a quality prompt and a reusable QP Generator.

03–05

Actors & outputs

Move from plain code to Gemini feedback and structured output.

06

The agent loop

Build a Teaching Assistant by hand and see the loop clearly.

07–08

Tools & teams

Measure attainment, then let graders, moderators, and writers collaborate.

10

Doubt-solving

Duplicate the loop and change the tools and instructions.

12

Attendance system

Build a decision agent around sample attendance data.

CAPSTONE

Their own agent

Apply the cores and tool library to a problem they choose.

THE LESSON

Less code, more agency

Several builds share the same sixty-line loop. Only the tools change.
