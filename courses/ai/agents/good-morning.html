Good Morning Telegram Agent

The simplest possible n8n agent — just 2 nodes. Every morning at 8 AM it automatically sends a "Good Morning" message with today's date to your Telegram chat. No OAuth, no Google Cloud, no paid APIs.

Beginner 2 Nodes Scheduled Trigger Telegram Bot API

How It Works

Architecture

[ Schedule Trigger ] Fires every day at 8:00 AM ↓ [ HTTP Request → Telegram Bot API ] Sends "Good Morning!" message to your Telegram chat
✅ Total nodes: 2  ·  Trigger: 0 8 * * * (8 AM daily)  ·  API: Telegram Bot API (free, no billing)

Sample Telegram Message

🌅 Good Morning! Have an amazing day ahead! 😊 Wednesday, 22 July 2026

Build Guide

Step-by-Step Setup

1

Install Docker & Run n8n

Install Docker Desktop, then run n8n locally:

docker run -d \ --name n8n \ --restart unless-stopped \ -p 5678:5678 \ -v n8n_data:/home/node/.n8n \ docker.n8n.io/n8nio/n8n

Wait 30 seconds, open http://localhost:5678, and create your local account. New to Docker? Follow the full Docker & n8n Setup Guide →

2

Create Your Telegram Bot

Message @BotFather on Telegram, send /newbot, choose a name and username (must end in "bot"). Copy the Bot Token it gives you.

3

Start a Chat With Your Bot

Search for your bot by username and click Start. Telegram blocks messages from bots you haven't started a conversation with.

4

Get Your Telegram Chat ID

Message @userinfobot to get your ID instantly, or visit https://api.telegram.org/botYOUR_TOKEN/getUpdates and read the "chat":{"id":...} field.

5

Import the Workflow

In n8n, click + → New Workflow → ... → Import from file, and select good_morning_telegram.json from the repo.

6

Configure the Send Node

Open the Send Good Morning node. Replace PUT_YOUR_BOT_TOKEN_HERE in the URL with your Bot Token, and PUT_YOUR_CHAT_ID_HERE in the JSON body with your Chat ID (keep the single quotes).

7

Test & Publish

Save with Cmd+S, click Execute workflow — both nodes should turn green and the message should land on Telegram instantly. Click Publish to activate the daily 8 AM schedule.

Configuration & Troubleshooting

Configuration Reference

Message text"Send Good Morning" node → JSON Body → text
Recipient"Send Good Morning" node → JSON Body → chat_id

Current schedule is 0 8 * * * (every day). For weekdays only, use 0 8 * * 1-5.
