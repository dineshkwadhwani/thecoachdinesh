Setting Up Docker & n8n

Every agent in this library runs on n8n inside Docker. Complete this setup once — in about 10–15 minutes, on Mac or Windows — and you're ready to build all five agents. No prior technical experience needed.

Required Setup ~15 Minutes Mac & Windows 100% Free

Part 1

🐳 Installing Docker Desktop

Docker runs software in isolated "containers" — think of a container like a sealed box containing everything n8n needs to run, with no messy installation and no conflicts with other software on your laptop.

1

Go to the Docker Website

Open your browser and go to docker.com/products/docker-desktop

2

Download for Your Operating System

🍎 Mac
  • Click "Download for Mac"
  • Apple Silicon (M1/M2/M3) → "Mac with Apple Chip"
  • Older Intel Mac → "Mac with Intel Chip"
  • Not sure? Apple menu → About This Mac → check "Chip"
🪟 Windows
  • Click "Download for Windows"
  • Download the .exe installer
  • Requires Windows 10/11 (64-bit)
  • WSL 2 must be enabled (Docker will prompt if needed)
3

Install Docker Desktop

🍎 Mac
  1. Open the downloaded .dmg file
  2. Drag the Docker icon into Applications
  3. Open Docker from Applications or Spotlight
  4. Enter your password if macOS asks
🪟 Windows
  1. Double-click the downloaded .exe
  2. Click Next through the wizard, accept defaults
  3. Restart your computer if prompted
  4. Docker Desktop launches automatically after restart
4

Wait for Docker to Start

When Docker Desktop opens, wait for the status at the bottom left to say "Engine running" in green.

First launch can take 1–2 minutes. Don't close the window — wait for the green status.
5

Verify Docker Is Working

Open Terminal (Mac: Cmd+Space → "Terminal") or Command Prompt (Windows: Windows key → "cmd") and type:

docker --version

You should see something like Docker version 27.x.x

Part 2

🤖 Installing & Running n8n

n8n is the automation platform where you'll build every agent. We run it inside Docker with a single command — your workflows are saved permanently, even across restarts.

1

Open Terminal or Command Prompt

Mac: Cmd+Space → type "Terminal" → Enter. Windows: Win+R → type "cmd" → Enter.

2

Run n8n Using Docker

Mac / Terminal:

docker run -d \ --name n8n \ --restart unless-stopped \ -p 5678:5678 \ -v n8n_data:/home/node/.n8n \ docker.n8n.io/n8nio/n8n

Windows / Command Prompt (uses ^ instead of \):

docker run -d ^ --name n8n ^ --restart unless-stopped ^ -p 5678:5678 ^ -v n8n_data:/home/node/.n8n ^ docker.n8n.io/n8nio/n8n
First time: Docker downloads n8n automatically (~500MB), which takes 1–3 minutes. Scrolling text is normal — wait until it stops.
3

Wait for n8n to Start

Give it about 20–30 seconds to initialise after the command finishes.

4

Open n8n in Your Browser

Go to http://localhost:5678 in Chrome, Firefox, Edge, or Safari.

5

Create Your Local Account

Fill in any name, any email, and any password you'll remember.

🔒 Privacy note: this account is stored only on your laptop. Nothing is sent to the internet, and n8n never asks for payment or personal details.

✅ Success signal: the n8n "Overview" dashboard appears with tabs for Workflows, Credentials, Executions, Variables, and Data tables.

🔄 After Restarting Your Computer

Because we used --restart unless-stopped, n8n restarts automatically on every reboot — as long as Docker Desktop is running. After a reboot: open Docker Desktop, wait for "Engine running", then go to http://localhost:5678 — your workflows and credentials will all still be there.

Make Docker Desktop launch automatically at login: Docker Desktop → Settings → General → "Start Docker Desktop when you sign in to your computer".
