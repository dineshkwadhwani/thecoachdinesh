Hands-On Assessment

Lab Tests

Four real engineering challenges. No multiple-choice questions. Every lab produces something you built — an artifact that proves capability, not just comprehension.

Primary Lab Test 1

Generative AI with ChatGPT & Groq

Experience the full GenAI production cycle — from prompt to structured output to analysis.

📄 Download Lab PDF

This lab immerses you in the practical reality of working with Generative AI tools at a production level. You'll move from simple prompt-and-response to systematic experimentation — testing how different phrasings, system messages, and model parameters (temperature, top_p) produce meaningfully different outputs.

Using both ChatGPT (OpenAI) and Groq's fast inference API, you'll compare output quality, speed, and cost across platforms for the same task — exactly the kind of decision engineering teams face when selecting AI infrastructure.

What You'll Deliver

A structured comparison report showing prompt variations, temperature experiments, cross-platform comparisons, and your analysis of output quality, hallucination risk, and production suitability.

Related Sessions

Sessions 1, 2 & 3 — AI fundamentals, LLM mechanics, prompt engineering

Skills Tested
Prompt Design Temperature Tuning Model Comparison Output Analysis API Usage
Tools

ChatGPT (OpenAI), Groq API, Python or no-code interface

Primary Lab Test 2

AI Agents with n8n & Llama

Build your first autonomous AI agent — no hand-holding, real automation.

📄 Download Lab PDF

This lab takes you from talking to AI to building AI that acts. Using n8n (a visual workflow automation tool) and Llama (Meta's open-source LLM family), you'll design and deploy an AI agent that can execute a multi-step workflow autonomously — without you pressing each button.

The shift from "GenAI as a chat tool" to "AI as an automated worker" is one of the most significant in the field. This lab gives you hands-on experience with that shift, including the debugging, edge cases, and design decisions that come with building agentic systems.

What You'll Deliver

A working n8n workflow that uses Llama to autonomously process inputs and produce structured outputs, with documentation of design decisions and observed failure modes.

Related Sessions

Sessions 3, 4 & 11 — Prompt engineering, structured outputs, multi-agent systems

Skills Tested
Workflow Design Agent Architecture Open-Source LLMs Tool Integration Error Handling
Tools

n8n, Llama (via Ollama or Groq), optional: LangChain

Primary Lab Test 3

End-to-End AI Application

Architect and ship a complete AI system — retrieval, generation, structure, all connected.

📄 Download Lab PDF

This is where everything from Sessions 1–8 converges. You'll build a complete, end-to-end AI application — not a demo, not a single prompt, but a system with distinct components that work together: a retrieval layer, a generation layer, structured output parsing, and basic error handling.

The hiring AI running project provides a natural template: a system that takes a candidate profile and a job description, retrieves the most relevant criteria via RAG, generates a structured assessment, and returns a formatted, machine-readable result. You may adapt this to any domain you choose.

What You'll Deliver

A working application (script, notebook, or simple API) with architecture documentation, test cases demonstrating correct behaviour, and a documented failure analysis.

Related Sessions

Sessions 4, 5, 6, 7 & 8 — Structured outputs, RAG, fine-tuning, evaluation, deployment

Skills Tested
System Architecture RAG Pipeline JSON Parsing End-to-End Testing Documentation
Tools

Python, OpenAI/Anthropic API, Chroma or Pinecone, any vector embedding model

Primary Lab Test 4

Production AI System Design

Design, document, and defend a production-ready AI system from first principles.

📄 Download Lab PDF

The final lab is a capstone engineering design challenge. You'll design a complete production AI system — from architecture and data pipeline through to deployment strategy, monitoring plan, safety audit, and cost model. This is what senior AI engineers and architects do before a single line of code is written.

Your design will cover: model selection rationale, infrastructure choices, scaling strategy (to 100K+ requests/day), caching plan, safety and bias testing approach, and cost optimisation. You'll also identify failure modes and document your mitigation strategies.

What You'll Deliver

A production system design document (10–20 pages or equivalent) covering architecture, infrastructure, deployment, monitoring, safety, cost, and scaling — ready for stakeholder review.

Related Sessions

Sessions 8, 9, 10, 11 & 12 — Production, optimisation, safety, advanced architectures, capstone

Skills Tested
System Design Infra Planning Safety Audit Cost Modelling Stakeholder Comms
Format

Design document + optional architectural diagram. Defend your choices.
